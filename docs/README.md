## Tech Stack

- **Backend**: Laravel 12 (PHP 8.2+)
- **Database**: SQLite (dev) / MySQL (prod)
- **Frontend**: Bootstrap 5, Tailwind CSS, Alpine.js
- **AI**: Ollama (local LLM) for RAG-based chatbot
- **Auth**: Laravel Sanctum
